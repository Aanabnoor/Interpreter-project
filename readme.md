### 2-What it does:
>My self made interpreter is a project where you can initialize and declare three variables and perform two functions.\
The syntax is:
- ***take command to declare a variable of any name***. 
 - ***Save*** it in the memory using ***store command***.
 - ***Display*** the result using ***display command***.

 >Since it is my first project so it is quite small it only calculates average of three numbers given by the user and also find what's the biggest number.

 ---
### 3-How to run it:
>To use it you have to make a txt file in the same folder where the c++ file will be otherwise it will give an error.\
And simply you have to follow the syntax in your txt file and the compiler will generate the result for you.
